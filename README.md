# Orbit Quiz

Orbit Quiz is a responsive, single-page space trivia game. Answer 10 multiple-choice questions, get immediate feedback, track your score, and see your results at the end. It uses plain HTML, CSS, and JavaScript, with no dependencies or build step.

## Run locally

Open `index.html` in a web browser. No installation or server is required.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` publishes `index.html` to GitHub Pages whenever a commit is pushed to `main`. It can also be run manually from the Actions tab.
